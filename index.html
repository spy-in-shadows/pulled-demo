pulled

After you pull, it tells you what's out of sync and the one command that fixes it.

The problem

You pull, start the app, and it crashes with column "avatarUrl" does not exist. Twenty minutes later you find out a teammate changed the Prisma schema and added a migration. Or bumped a dependency. Or added a new key to .env.example.

pulled compares what the code expects with what's on your machine (node_modules, Node version, .env, the Prisma client and migrations) and stays completely silent when everything matches. No git hooks, no stored state, no setup.

Three ways to run it

First line of your app

import 'pulled';

Or require('pulled'). Checks on every dev start.

No code change

node --import pulled server.js

Put it in your "dev" script.

CLI

npx pulled --fix

Exit code 1 when out of sync; --fix runs the fixes.
